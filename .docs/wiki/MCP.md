# MCP

The real FormRef MCP server exposes board operations through the same live store/core used by the app. The repository-local harness provides sequencing and recovery; it does not substitute for tool access.

Run the backend through `./formref dev` or production `./formref serve`, then register the absolute repository `formref` executable with argument `mcp` as a stdio server. Set the client working directory to the repository. If no local API is running, the MCP server starts its own loopback API and closes that owned process when the connection ends. `FORMREF_API_URL` changes the loopback service URL; `FORMREF_PYTHON` changes the launcher's interpreter. Original files supplied by path must stay beneath `FORMREF_MCP_IMPORT_DIR` (default `~/.formref/imports`); raw base64 is also accepted.

Once connected, discover the server. Actual SDK discovery returned 47 tools, including `remove_background` (by edge colours or by one of FormCut's models, including SAM 2.1 with points; the original kept; `restore` puts it back), `list_background_models` and `download_background_model`, `create_table` for table cards with typed columns and formulas, `capture_from_web` (an image address is placed, a page address lists its images), `define_labels` and `label_items` for coloured labels, `add_comment` and `resolve_comment` for item comment threads, `list_templates` and `create_board_from_template`, and `list_trash` and `restore_from_trash` for putting removed items or deleted boards back: `list_boards`, `create_board`, `get_board`, `get_board_image` (the board as a picture for models that read images), `add_items`, `update_items`, `arrange_items` (including sort), `adjust_items` (rotate, opacity, image flags, crop), `transform_items`, `remove_items`, `undo`, `redo`, `import_asset`, `export_board`, `search_items`, `connect_items`, `configure_canvas`, `snap_items`, `sample_image`, `create_swatch`, `create_document` and `set_formatted_text`. Resources expose board discovery and a board by ID; the `organize_references` prompt supplies an organization workflow. Live schemas decide exact parameters. Canvas settings and snap are shared Rust mutations with persistence, revisions and undo; see [Engine contract](Engine-Contract.md). Image sampling returns original source-pixel RGBA/RGB/HSV/HEX and coordinates without adding history. `find_by_color` (v0.8.0) is read-only too: give a #RRGGBB colour and an optional tolerance and it returns the pictures and swatches containing it, best first; `arrange_items` sorts with the key `color` for rainbow order. `find_similar` (v0.9.0), also read-only, takes a picture's item ID and a level (close, related or loose) and returns the pictures that look like it plus a score for every other picture. `save_search` and `delete_search` (v0.10.0) keep named searches on the board (find text, kind, colour with tolerance, a similar picture and level, and from v0.11.0 tags and label ids items must all carry); the person applies them from the bookmark beside the item count. A search with the same name, ignoring case, is replaced. `rename_tag` and `remove_tag` (v0.12.0) change a tag, matched ignoring case, on every unlocked item as one undoable batch; renaming to a name another tag has merges them without duplicates, and the result counts changed and locked items. Swatches store canonical HEX, documents retain literal source plus plain/Markdown format, and formatted-text updates preserve other item data while rejecting stale revisions. The safe subset, normalized sample mapping and conditional-save limits are in [Engine contract](Engine-Contract.md). Outside clients send `X-FormRef-Client` and are refused with 403 until you allow outside agents in the Agent panel; FormRef shows a prompt the first time one is refused.

To arrange a board, call `list_boards`, get the intended board, retain exact item IDs, arrange those IDs, then get the board again. Check geometry and revision rather than relying on an acknowledgment alone. Successful tool mutations persist and send board revision events to the frontend.

A timeout may follow a completed mutation. Read back before retrying; retain returned asset/item IDs to avoid duplicate imports. Reverse only confirmed operations with Undo when rollback is requested.

If every change is refused with 403 `outside_agents_off`, the person has not allowed outside agents yet: ask them to answer the "An outside agent wants to edit" prompt in the FormRef window with Allow outside agents, or to tick the box in the Agent panel (see [Agent](Agent.md)); do not retry in a loop, and note that the agent cannot change that choice itself. If calls fail some other way, check connection status, `/api/health`, absolute command/cwd, engine availability and filesystem permissions. The default service is local and does not need a cloud credential. Rediscover missing tools; isolate a failure by calling the tool directly without the harness workflow. Report the observed error rather than claiming an installed configuration is a working connection.

When you change a tool, a skill or the dock in the repository, run `./formref agents sync`: it copies `.claude/skills` to `.agents/skills`, writes `agents/manifest.json` (the tool list, which tools are read-only and which can wait for the person's Allow, the skills and the dock) and, with the window open once, the command reference. `./formref agents sync --check` fails, naming the file, while any of them is out of date. `CONTRIBUTING.md` has the details.
