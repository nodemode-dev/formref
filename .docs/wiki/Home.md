# FormRef

FormRef combines an infinite image-reference board with notes, links, relationship lines, columns, tasks and nested-board cards in the Form family visual system. Its board engine is Rust, its local service is Python/FastAPI and its frontend is vanilla TypeScript/Vite.

Start with [Getting Started](Getting-Started.md), then use [Canvas](Canvas.md), [Files](Files.md) and [MCP](MCP.md). [Architecture](Architecture.md) describes shared command ownership; [Releases](Releases.md) explains reproducible delivery and honest parity scoring.

The measured scope is local reference-board work. Native always-on-top/click-through window modes, proprietary PureRef/BeeRef project formats and hosted Milanote collaboration require separate implementations. Consult the repository parity matrix for the status of each researched behavior.
