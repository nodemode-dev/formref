# Comparison font notices

The FormRef comparison uses the same four font families as the final FormVis comparison. Instrument Sans is body/evidence text, Bricolage Grotesque is headings, Archivo is capability charts and percentage tiles, and JetBrains Mono is table headers/status badges/source notation. Original font files remain unmodified and are served by Google Fonts; no font binary is fused into the application. License texts are retained below and linked from the comparison's evidence section.

The authoritative notices were fetched from Google's font repository on 2026-10-10. OFL-1.1 applies to the font software, not FormRef's independently authored code or documents. The comparison does not claim authorship of the fonts or endorsement by their creators. The exact CSS/font URLs and hashes used for visual verification are recorded outside the application in the planning sidecar's font evidence. Browser verification distinguishes custom font glyphs from fallback fonts; declared family names alone are not proof of loaded typography.
