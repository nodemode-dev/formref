VECTOR TOOLS

Off by default. Adds the Pen, Curvature, Pencil and Direct Selection tools, path editing and corners, Pathfinder, polygons, stars and other shapes, stroke and gradient options, and Smart Guides. Paths already on a board stay visible either way.

Browser workspace: canvas, files, local persistence and MCP automation are available. Native window controls appear only in the desktop shell.

DESKTOP WINDOW

Ctrl+Alt+F (Cmd+Option+F on a Mac) brings FormRef to the front from any app, or hides it when it is in front. The tray icon does the same on click, and its menu holds Always on Top, Click-through and Quit.

BROWSER CLIPPER

Load the clipper folder in Chrome (Extensions, Developer mode, Load unpacked) or Firefox (about:debugging, Load Temporary Add-on), then paste this token into its options. Web pages cannot save to FormRef without it.

CLOUD STORAGE (OPT-IN)

Off until you connect. Uses your own app credentials; FormRef has no account or server in between, and tokens stay in the local service. Agents cannot move files to or from the cloud.
